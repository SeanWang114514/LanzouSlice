# 蓝奏切片 · Windows 桌面版

从新下载的 CYQawa/YunX 源码移植蓝奏云协议，重新实现的分片上传与自动下载合并软件。未使用此前的网页或扩展实现。

## 启动

0.1.32 便携版位于 dist/v0.1.32/LanzouSlice-win32-x64/。双击其中的“蓝奏切片.exe”。请保留整个文件夹，不能只复制 exe。压缩包和对应源码包也在 dist/v0.1.32/，其他版本目录保留为旧版。

开发运行：

    npm install
    npm start

要求 Node.js 22.12 或更高版本。打包：npm run package。

## 本版改动（0.1.32）

- 上传页面增加已选文件列表。勾选不准备上传的文件后点击“移除所选”，支持单项、批量和全选移除，剩余文件的数量及总大小同步更新；全部移除后恢复空选择状态。
- 移除只影响本次上传选择，不删除本地原文件，也不取消已经入队的任务。登录后拖拽仍直接排队；需要先筛选文件时，请点击文件选择框选择，再移除多余文件后点击“切片并上传”。已入队任务在“上传下载”页取消。
- 选择文件或提交上传期间锁定移除控件；取消文件对话框保留原有列表和勾选。列表固定高度滚动，长文件名省略并可悬停查看完整路径，进度更新不重建文件行。验证结果见 dist/v0.1.32/发布校验.json。

### 0.1.31 保留功能：智能识别刷新修复

- 刷新重新读取云端目录，但不删除已有原名缓存。切片预览 5 分钟、普通目录 1 分钟内复用；过期结果保留展示，在后台复核。改名、管理操作和账号切换仍按原规则失效，远端已删除目录不会因缓存重新出现。
- 单个后台目录识别最多等待 12 秒，保持 2 个工作槽位。网络、限流、验证页或超时暂时失败时保留预览，提示更新未完成；已确认普通目录或清单／切片无效时清除旧提示。
- 预览只用于显示原名，下载前仍重新读取正式清单、检查成员及 SHA-256 校验。首次识别仍取决于网络与目录规模；12 秒是单目录等待上限，不是全部目录的完成时间。验证范围见 dist/v0.1.31/发布校验.json。

### 0.1.30 保留功能：开机自启修复

- 修复开启开机自启时误报“Windows 未应用开机自启设置”。写入使用专属的 `LanzouSlice` 启动项，现按当前程序路径、启动项名称、用户范围及该项启用状态核对，避免 Electron 默认应用标识的返回值导致成功写入后被误回滚。
- 保留系统禁用、真实写入失败及设置保存失败的保护；其他同路径启动项的状态不会替代本软件启动项。写入仍带 `--autostart`；Electron 的 `launchItems.args` 不含这类开关，不用它误判启动命令。
- 使用新版时，请先放到固定目录，打开“设置与清理”重新开启“开机自启”；如需开机后只驻托盘，再开启“静默启动”。便携版移动位置后仍需重新开启自启。
- 新增 `npm run test:startup` 原生 Windows 专项检查，可追加成品 EXE 路径。只创建随机名称的临时测试启动项，在结束时清除，检查真实注册、系统禁用、重新启用与失败回滚；不重启电脑。最终成品及归档一致性结果见 `dist/v0.1.30/发布校验.json`。

### 0.1.29 保留功能

- “上传下载”页增加单项“取消”和“取消所选”。手动上传、普通下载、切片下载的排队／运行／暂停／失败任务均可取消。取消会等待传输与任务日志写入停止，保存为“已取消”，不再支持继续；需要重传时请新建任务。
- 取消只清理可确认归属的临时缓存，保留本地原文件、已完成下载、未知文件及云端已经上传的内容。已完成的任务不会被改为已取消。保存失败时保留暂停任务和缓存，可重试；缓存清理失败时保留已取消记录并提示，可在设置中再次清理缓存。
- 点击任务空白区域选择一项；Ctrl 点击增减选择；Shift 按当前筛选顺序连续选择；Ctrl+Shift 追加范围。复选框也支持这些修饰键，可本页全选、清除选择，每次最多选 200 项。翻页和进度更新保留选择，切换筛选／账号后清空选择；任务详情和操作按钮不触发选择。
- 每页仍只创建 50 张任务卡，继续复用节点和隐藏页按需渲染。新增“已取消”筛选与数量；“清空全部历史”和单条“移除记录”支持已取消记录。“清空已完成”不清除已取消记录。
- 自动同步任务继续在同步页面暂停／管理规则，不参加传输页选择与取消，避免下一轮同步重新生成任务。批次正在准备、暂停或历史正在清理时，取消会提示稍候再试。

### 0.1.28 保留功能

- 上传区支持批量拖拽和原生窗口多选，每批 1–200 个实际文件，显示数量及合计大小。已登录时拖入自动加入队列，有传输正在运行时追加到队尾；未登录时只保留本次选择，登录后点击“切片并上传”。窗口多选后同样点击按钮提交。
- 每个文件建立独立上传任务及云端目录，和下载任务共用顺序队列；一次只运行一个文件，文件内切片沿用上传并发设置。排队只保存元数据，轮到任务才计算 SHA-256 和生成切片，不提前读取整批文件内容。
- 暂停全部或切换账号会停止正在提交的批次。源文件丢失等单项准备失败会跳过并说明，其余文件仍可入队；已建立但保存失败的任务保留为暂停，在“上传下载”中检查和继续；尚未建立任务的文件保留在选择区，重试不会重新提交本批已建立的任务。传输中单项失败继续下一项，登录失效暂停剩余任务。
- 不递归上传文件夹。超出上限或混入文件夹、网页虚拟文件时，本次选择不提交并保留之前的选择。批量拖入的顺序以系统传递的文件顺序为准；队列支持单项暂停、继续与暂停全部，重启后未完成任务恢复为暂停。

### 0.1.27 保留功能

“设置与清理”新增三个独立开关，均默认关闭，自动保存：

- **开机自启**：登录 Windows 后启动当前便携版程序。仅打包后的 Windows 程序可设置；移动文件夹或换用另一版程序后，需在新位置重新开启，并确认 Windows“启动应用”允许本软件。
- **静默启动**：下次启动只显示托盘图标。单击或双击托盘、右键“显示主窗口”、再次打开软件均可恢复窗口；右键“打开设置”直达设置页。只开启开机自启仍正常显示窗口，同时开启静默启动才在后台启动。
- **关闭到托盘**：点击右上角关闭按钮时隐藏窗口，上传、下载及同步继续。要彻底退出，右键托盘选择“退出软件”；退出会暂停传输并保存记录。关闭此开关恢复原有关闭即退出行为。Windows 注销和关机不受关闭隐藏逻辑拦截。

后台自动同步需要已启用的规则和有效的记住登录会话；会话失效时请恢复窗口登录。完全退出或关机后不会执行计划。托盘不可用时静默启动回退为显示窗口，避免软件无法找回；隐藏期间保留上一版的零界面状态推送策略，不停止后台传输。

启动与托盘专项验收：`npm run test:lifecycle`；打包后可传入 EXE 路径。该测试使用独立配置和模拟开机启动 API，不更改真实 Windows 启动项，也不重启电脑。

### 0.1.26 保留功能

## 自动同步（0.1.22 起）

1. 登录后进入“自动同步”，选择一个文件、文件夹，或填写本机绝对路径。文件夹会递归扫描；同名文件按相对路径分别管理，跳过链接以免循环扫描。
2. 选择云端父目录（默认根目录），填写规则名。每条规则独立选择“按时间间隔”（1–10080 分钟）或“每天指定时间”（如 `09:00, 14:00, 20:30`，最多 24 个，按电脑本地时间）。
3. 保存后到点自动执行，也可以点击“立即同步”。规则卡片和专用同步浮窗显示整轮进度，包含已处理／总文件数与大小、速度、已用时间、预计剩余时间，以及新增、更新、跳过、删除、失败统计；“上传下载”仍可查看单个切片任务详情。进度总大小包含跳过的文件，速度仅统计本轮实际上传流量（含封装与清单）；预估只在有上传样本时提供，清理与提交未完成时不会提前显示 100%。可以编辑时间、暂停、启用或移除规则；源路径和云端目标固定，更换时另建规则。
4. 默认关闭“同步本地删除”。开启时需确认，之后才清理这条规则已管理且本地已移除的文件；其他规则和手动上传不受影响。移除规则始终保留云端内容。

这是本地到蓝奏云的**单向增量同步**：按 SHA-256 内容摘要比对，未变化不上传，仅修改时间也不重传。新增或修改的文件按现有切片协议完整上传，正式清单和成功记录保存后才清理旧版，不是按时间重复上传整套文件，也不是二进制差分上传。云端版本、清单或分片丢失时会重建对应文件。每轮会读取云端目录核对状态，因此“未变化不上传”仍有目录查询请求。

每条规则建立独立的 ASCII `sync规则ID` 目录；各文件版本使用兼容的 `slice任务ID` 目录，正式清单的 `naming.relativePath` 保存子目录相对路径，按此区分同名文件。云端原始视图不直接重建本机的中文目录树，单文件下载沿用现有原名还原流程。更新后原分享链接可能变化。

规则、摘要基线、回执和未完成任务快照单独保存在本地任务目录的 `sync-rules.json`，清空传输历史不会丢失成功基线；正在恢复的同步任务保留。上传失败保留旧成功版本，重试复用已确认切片；源路径缺失、权限错误、扫描失败、路径变为链接时停止本轮，不当作全部删除。拒绝同账号下源路径重叠的规则，任务/缓存目录不能作为同步源，账号切换先停止当前同步。

同一时间只运行一条规则；规则内的多个文件与切片共享上传并发上限，手动传输仍按任务顺序执行。多个未完成同步文件分别保存回执，新版可迁移旧版单文件回执。手动传输排队期间自动同步等待。同步的扫描、传输和清理阶段可接收手动上传、下载并排队，在本轮同步结束后执行；管理云端文件仍需先暂停同步。暂停单条规则会停用其后续计划，“暂停全部”也停用当前账号的同步规则；“立即同步”或浮窗“继续同步”可在规则停用时手动执行一次，恢复定时执行请启用规则。软件运行、最小化或隐藏到托盘时执行计划；完全退出、关机期间不运行，重新打开并登录后将错过的计划合并执行一次，不逐次补传。0.1.27 起可在设置中开启开机自启和托盘选项；未增加 Windows 服务或双向同步。

同步专用桌面验收：`npm run test:sync`；打包后：`npm run test:sync -- "dist/v0.1.29/LanzouSlice-win32-x64/蓝奏切片.exe"`。均使用独立配置和本机模拟服务，不访问真实账号。

传输取消与选择专项：`npm run test:transfers`；成品验收：`npm run test:transfers -- "dist/v0.1.29/LanzouSlice-win32-x64/蓝奏切片.exe"`。使用隔离合成任务和真实鼠标修饰键事件；实际传输取消另由本机 HTTP 回归覆盖，不使用真实账号。

## 图标优化（0.1.19）

账号、上传、下载、关闭及文件类型统一为本地 SVG 线性图标，替换字体箭头、字符图标和四宫格。移除上传与账号图标的装饰底座，文件类型使用灰色，切片文件保留紫色识别提示；操作按钮继续保留文字。

## 上传

1. 在软件左侧输入蓝奏云账号密码登录。密码只用于本次登录，不落盘。
2. 如果要求人机验证，点击“打开官网登录窗口”，在官网手动完成登录，再点击“我已登录，检测会话”。
3. 可选“在此电脑记住登录”：仅把会话通过 Windows 系统加密保存在本机；不保存密码。
4. 选择原文件，点击“切片并上传”。
5. 软件计算原文件 SHA-256，在根目录自动建立仅含英文字母和数字的 `slice任务ID` 目录，按设置并发上传切片，全部成功后提交正式清单，再补充可选的快速索引。原文件名中的特殊符号不会作为云端目录名提交。
6. 任务完成后可复制文件夹分享链接，也可导出本地清单。

### 拖拽上传（0.1.2）

把本机文件拖到上传区域即可选中，拖入时区域高亮。已经登录时，松开后加入传输队列：空闲立即开始切片上传，有任务运行则排队等待；尚未登录时保留选中文件，登录后点击“切片并上传”。

每批支持 1–200 个实际文件，也可点击上传区在原生文件窗口中使用 Ctrl/Shift 多选。文件夹、网页链接或浏览器创建的虚拟文件会显示说明，不会改动之前选中的文件。拖拽通过 Electron 的 `webUtils.getPathForFile` 获取本机路径，再由主进程逐个验证文件，不把整个文件读进界面内存。

每片实际上传文件不超过 80 MiB（83,886,080 字节），不是十进制的 80,000,000 字节。切片为有效 ZIP Store 容器，内部 payload.bin 是原文件的一个区间。为 ZIP 头尾保留 512 字节，单片有效载荷为 83,885,568 字节；末片可以更小。切片不能独立安装或打开原文件，需要软件还原。

## 下载与合并

1. 切换到“下载与合并”。
2. 使用“我的蓝奏云”，默认“智能识别”模式。已知切片目录直接复用当前账号的原名缓存，首次遇到的目录在后台逐项读取快速索引或正式清单；普通文件夹照常显示，可进入子目录。行内点击“下载并合并”会完整校验清单再开始，无需填写分享链接或提取码。点击原文件名可先查看详情；外部分享仍可通过完整分享链接和必要提取码读取。
3. 确认保存目录和并发数量（默认 4，范围 1–8）。默认保存到系统“下载”目录下的“蓝奏切片”子目录，可在下载页或设置中更改。
4. 如果先读取详情或分享清单，点击底部“下载并合并”。软件同时下载多个切片，每片按清单验证大小与 SHA-256，再按编号读取 ZIP 内的有效载荷并合并。
5. 最终文件大小与原文件 SHA-256 一致后才报告成功。不覆盖目标目录已有的同名文件。

### 文件名快速索引（0.1.8）

- 新上传完成后，在切片目录额外上传一个 `sliceindex1…txt` 小文件。文件名把原名（包括中文与特殊符号）、原大小、切片数和正式清单 ID 压缩编码为 ASCII 十六进制，并附摘要检查位。目录名继续使用安全的 `slice任务ID`；完整原名和 SHA-256 仍保存在正式清单中。
- 智能识别仍需列出每个候选目录的完整成员，但有有效索引时不再为列表显示而获取清单分享地址、解析下载页、取下载签名或下载清单。单页模拟目录的对照测试为 3 次目录请求，对比完整识别 8 次请求，减少 5 次（62.5%）；不是实际平台耗时或固定倍速承诺，多页目录仍需分页。
- “快速预览”只是发现提示，并非已验证文件。读取预览时检查正式清单 ID、完整片数、切片顺序名称及重名；点击原名或“下载并合并”仍重新下载正式清单，核对切片 ID，再按 SHA-256 下载与合并。索引文件不能代替正式清单或改变下载文件身份。
- 索引只在正式清单提交之后上传。索引上传失败不影响已完成文件；任务卡片会显示说明，继续使用完整清单。索引提交时暂停，继续任务会复用已确认或响应丢失的同名索引，避免重复上传。
- 旧目录无需迁移。索引缺失、格式损坏、重复、清单 ID 不匹配或成员不完整时自动回退完整清单；旧目录不会自动被写入新文件。编码后索引文件名超过 240 个 ASCII 字符时跳过索引，保留完整原名，继续完整清单识别。
- 读取完整清单后，目录内智能视图将匹配的索引和切片一起折叠；原始网盘模式仍可查看这些实际文件。缓存和历史清理识别本机 `slice-index.txt` 临时文件，保留原有归属及恢复保护。

### 并发传输（0.1.6）

- 打开“设置与清理”，在“传输并发”中分别设置上传和下载路数，均支持 1–8 路；默认上传 2 路、下载 4 路。设置自动保存，重启后保留。
- 下载页底部的并发选择与设置中的下载并发同步；上传页和任务卡片显示对应并发数量。
- 新任务使用最新设置。运行中的任务保持启动时的并发；暂停或失败后点击“继续”，使用最新保存的设置。
- 并发针对一个文件的多个切片，同时仍只运行一个传输任务；实际并发不超过剩余切片数。每片上传不超过 80 MiB，不对单片额外开启多个上传连接。
- 上传按工作槽位生成并提交 ZIP，确认成功后释放该片缓存，再处理下一片；并发越高，需要同时保留的上传缓存越多。遇到网络或平台限速，可调低路数。
- 切片可以乱序上传完成，正式清单仍按编号排序，全部成功后只提交一次；暂停或失败会等待并发请求退出，保留已确认回执供恢复使用。

### 自动识别、目录与清理（0.1.5）

- 完成上传后再进入下载页，会自动刷新根目录并识别已上传文件。当前层的文件夹按批识别，最多两个文件夹同时读取；加载更多后继续识别，不递归扫描整盘。进入其他目录或切换账号时，迟到的结果不会覆盖当前界面。
- 真正名称来自云端 `manifest.lanzou.txt` 的 `originalName`，清空本地历史、换电脑后仍可重新识别。只显示名称映射，不修改实际云端兼容目录名；云端目录名仍保留供追踪。缺清单、重复清单、缺片等目录不能被当作可下载文件。
- “无需提取码”指已登录账号可访问的目录。软件自动按现有账号接口获取文件信息和下载链接；不会绕过外部分享密码或平台验证。
- “设置与清理”中可选择默认下载目录、切片缓存目录和自动清理开关。更改缓存位置时，会在所选位置建立 `LanzouSliceCache` 专用子目录；只影响新任务。已有任务继续使用其原始缓存与输出路径，旧版任务也按旧路径恢复。
- 新版切片缓存与任务日志分开：每个任务有独立 UUID 缓存目录及归属标记。暂停或失败的任务不会因为切换目录、普通缓存清理或“清空已完成”丢失恢复数据；0.1.9 的“清空全部历史”会明确包含失败记录。缓存和下载结果在不同磁盘时分别检查可用空间。
- 自动清理默认开启，在传输完成和校验成功后、以及启动时，清理已完成任务的残留切片。关闭后保留完成下载的切片供手动清理；上传时仍逐片释放已确认上传的 ZIP，以控制磁盘占用。
- “刷新占用”显示可清理缓存和受保护的恢复数据。“清理缓存”仅删除本软件可确认归属的已完成任务临时文件，不递归删除用户所选目录，不跟随任务缓存目录联接。
- “清空已完成”一键移除已完成上传/下载记录及可清理残留缓存；正在运行、暂停和失败的任务保留。原文件、最终下载结果、登录会话、目录设置及云端文件保留。

### 界面与操作（0.1.4）

- 文件列表按名称、大小、修改时间和操作分列，表头固定；文件夹、普通文件、压缩包和切片清单有不同图标。
- 长文件名和目录路径省略显示，悬停可查看完整内容；加载更多时保留列表滚动位置，进入目录时回到顶部。
- 已登录后的账号栏收起网页登录选项，点击“网页登录与会话”仍可打开；登录与隐私说明折叠显示。
- 上传区显示已选文件的名称、路径和大小；0.1.9 起任务位于独立“上传下载”页，详情可展开，实时进度移至右下角可收起浮窗。提示消息位于右上角。
- 保留原有蓝白风格和文件列表主导的布局，不改变蓝奏云登录、切片传输或校验协议。

### 文件浏览布局（0.1.3）

- 文件列表随窗口高度伸展，宽屏使用可用宽度；目录内容在列表内部滚动，保存位置、并发设置和下载按钮保留在底部。
- 下载标题缩小，移除下载区的宣传标题和重复说明。“读取清单”放入目录工具栏，下载设置合并为一行；完整保存路径可悬停查看。
- 分享链接入口保留紧凑表单，上传、分页、清单校验和原名恢复逻辑不变。

### 文件目录读取（0.1.2）

- 按固定版本 YunX 的 `LanzouApi.listCloudFiles`，使用 `doupload.php` 的 `task=47` 读取文件夹，`task=5` 和 `pg` 读取文件，沿用同一 Cookie 会话和 `uid/vei`。
- 已登录后首次进入“下载与合并”会读取第一页，点击“加载更多”继续读取，不必等待全部文件扫描完。界面显示已读数量、页码、文件大小与修改时间。
- 按 YunX 的字段优先级处理 `fol_id/id`、`name/name_all`，跳过空条目并去重；遇到重复文件页停止，防止无限翻页。读操作遇到频率限制或 HTTP 服务异常时，最多重试同一请求两次，不跳页。
- 目录成功读出后才更新路径；失败会保留原列表和原路径。退出/切换账号后，旧目录请求的迟到响应不会覆盖新状态。
- 找到 `manifest.lanzou.txt` 后，可直接点击该行的“读取清单”。清单检查和实际下载仍会读取完整目录、核对所有切片；浏览第一页不会被当作完整切片列表。

### 特殊符号与原名恢复（0.1.1）

- 上传时自动使用兼容的云端目录名，切片名仍为 `part-000001.zip` 等；不改动本地原文件，也不因原文件名中的符号弹出“名称含有特殊字符”。
- 云端 `manifest.lanzou.txt` 的 `originalName` 完整保留原名，`naming` 记录原名、云端目录名和命名策略。修复旧失败任务时还记录 `previousCloudFolderName`，任务卡片显示实际云端目录。
- 下载合并时直接恢复清单里的原文件名，包括中文、空格、括号、`&`、`+`、全角符号和 emoji 等 Windows 支持的字符。
- 如果来自其他系统的清单原名含 Windows 无法保存的字符（如 `:`、`?`、`/`、`\\`）、保留设备名、末尾点/空格，软件自动使用安全名称；过长名称保留短哈希避免截断混淆。完整原名仍保存在清单、本机 `task.json` 中，`nameRestoration` 记录原名与实际保存名，任务卡片会显示转换结果。Windows 禁用的字符不能直接作为文件名落盘。
- 旧版本因目录名报错的任务可在新版点击“继续”自动修复；已经存在的旧云端目录和 v1 清单继续兼容，避免重新上传已确认的切片。

本软件的“多线程”是多个切片并发传输，不额外对每个切片开启多连接；未完成切片仅在下载节点正确支持 Range 时按字节续传，否则重新下载该片。

## 暂停、关闭和恢复

- 任务运行时可点击“暂停”；退出软件会先暂停并保存任务。
- 重启后点击“继续”。已确认上传的片不重传；已下载的片重新校验后复用。
- 上传切片的单次请求中断后，按片重传，没有单片上传的字节级断点续传。
- 上传响应丢失时先查询远程同名片，并下载校验其 SHA-256，再确定是否重传，避免仅按名字/大小误判。
- 继续上传时原始文件必须留在原位置且内容未修改。
- 分享下载任务的提取码不写入任务日志；重启后如需要提取码，在分享入口重新填写，再点击任务“继续”。
- 成功后按“自动清理缓存”开关处理临时片；失败和暂停时保留恢复数据。不会自动删除云端内容。

## 数据与清单

点击“打开本地任务目录”可查看本机任务记录。默认位于 Electron 的用户数据目录 lanzou-slice-desktop。记住登录使用 session.bin（Windows 系统加密）；任务日志在 tasks/，设置在 settings.json，默认切片缓存在 cache/。退出账号会清除本地登录会话并暂停任务。新版账号传输任务绑定创建时的账号，切换账号后需登录原账号才能继续；旧日志没有账号标记时保持兼容。

正式清单为 manifest.lanzou.txt（UTF-8 JSON），包含原文件名、名称映射（新版上传）、大小、SHA-256、切片顺序、偏移、有效载荷长度、封装大小、切片 SHA-256 与远程文件 ID，不包含账号密码、Cookie 或临时下载直链。

正式清单在全部切片上传成功后才提交。下载入口拒绝缺清单、缺片、重名或无效清单。

第一版只支持本项目的新清单协议，不承诺兼容其他切片工具、此前已删除网页版本的旧清单、蓝奏云优享版或其他网盘。

    npm run test:desktop -- --test-data=.tmp/smoke-profile

- npm test：135 项本地测试，包含 25 项同步专项和 4 项资源优化专项，覆盖去重、更新、重启恢复、删除保护、账号隔离、计划计算及现有传输功能。资源紧张时使用 `node --test --test-concurrency=1 tests/*.test.mjs` 顺序运行。0.1.15 针对小切片并发检查，将该项模拟下载的块间隔从 2 ms 调为 40 ms，让两路请求有足够重叠时间；保留“恰好两路”的断言，生产传输代码未改动。
- test:large：160 MiB＋1 字节三片往返，验证上传文件不超 80 MiB，合并后 SHA-256 一致。使用离线文件服务，不是真实蓝奏云账号测试。

- test:features：启动独立 Electron 配置和本机 HTTP 服务，检查 131 项功能标志及 54 组布局，包括 Chromium 原生鼠标右键和修饰键多选、双击目录、运行中添加任务、上传下载、文件管理、浮窗、图标与主题。最终程序验证：`npm run test:features -- "dist/v0.1.26/LanzouSlice-win32-x64/蓝奏切片.exe"`。拖拽使用 Chromium File 与 DragEvent，打开目录记录系统打开意图，不实际弹出资源管理器。

- test:performance：独立 Electron 配置，构造 300 条历史和 25 Hz 合成进度，检查隐藏页、50 条分页、窗口最小化与恢复、节点复用和选择保留，记录应用各进程 CPU 与工作集合计；使用离屏软件渲染，不代表实际云端吞吐量。两轮源码对照数据和测量限制见 `性能优化验证.md`。

本轮没有蓝奏云账号，尚未完成真实账号的登录、80 MiB 上传与下载全链路验收。仅对未登录个人盘做了可达性和未登录识别检查。实际使用首次请先用一个小文件完成上传下载校验，再传重要或大量文件。不要将账号密码发送到聊天中，在软件本机输入即可。
