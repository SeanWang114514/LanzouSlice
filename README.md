# 蓝奏切片 · Windows 桌面版

从新下载的 CYQawa/YunX 源码移植蓝奏云协议，重新实现的分片上传与自动下载合并软件。未使用此前的网页或扩展实现。

## 启动

0.1.20 便携版位于 dist/v0.1.20/LanzouSlice-win32-x64/。双击其中的“蓝奏切片.exe”。请保留整个文件夹，不能只复制 exe。压缩包和对应源码包也在 dist/v0.1.20/，其他版本目录保留为旧版。

开发运行：

    npm install
    npm start

要求 Node.js 22.12 或更高版本。打包：npm run package。

## 应用图标（0.1.20）

应用标识重新设计为浅灰圆角底与靛蓝文件，两块错位的分片通过斜切缝组合成文件轮廓。左上角品牌、窗口和 Windows EXE 使用同一套素材；保留现有新拟态界面和操作图标。

## 图标优化（0.1.19）

账号、上传、下载、关闭及文件类型统一为本地 SVG 线性图标，替换字体箭头、字符图标和四宫格。移除上传与账号图标的装饰底座，文件类型使用灰色，切片文件保留紫色识别提示；操作按钮继续保留文字。

SVG 不依赖系统图标字体或网络资源。Windows ICO 含 16、20、24、32、48、64、128、256 px 八档尺寸；修改 `ui/assets/app-icon.svg` 后可运行 `npm run build:icons` 重新生成 PNG/ICO。

## 新拟态界面（0.1.18）

采用浅灰 `#e4e6ee` 表面、柔和双向阴影和少量紫色强调。面板、按钮与当前标签呈凸起效果，输入框、上传托盘和文件列表呈内凹效果；主面板使用 16 px 圆角。上传、下载与合并、传输管理、设置、右键菜单、确认框和右下角浮窗使用相同材质。

选中行保留复选框并增加左侧紫色标记；按钮按下时内凹，不缩放或改变布局。保留清晰的键盘焦点，支持系统减少动态效果与高对比度设置。文件列表和传输数字区域沿用已有尺寸，浮窗保持 344×128，收起为 344×48。

## 上传

1. 在软件左侧输入蓝奏云账号密码登录。密码只用于本次登录，不落盘。
2. 如果要求人机验证，点击“打开官网登录窗口”，在官网手动完成登录，再点击“我已登录，检测会话”。
3. 可选“在此电脑记住登录”：仅把会话通过 Windows 系统加密保存在本机；不保存密码。
4. 选择原文件，点击“切片并上传”。
5. 软件计算原文件 SHA-256，在根目录自动建立仅含英文字母和数字的 `slice任务ID` 目录，按设置并发上传切片，全部成功后提交正式清单，再补充可选的快速索引。原文件名中的特殊符号不会作为云端目录名提交。
6. 任务完成后可复制文件夹分享链接，也可导出本地清单。

### 拖拽上传（0.1.2）

把本机文件拖到上传区域即可选中，拖入时区域高亮。已经登录且没有运行中的任务时，松开后立即开始切片上传；尚未登录或另一个任务正在传输时，只保留选中文件，登录或完成/暂停当前任务后再点击“切片并上传”。

每次支持一个实际文件；同时拖入多个文件、文件夹、网页链接或浏览器创建的虚拟文件会显示说明，不会改动之前选中的文件。拖拽通过 Electron 的 `webUtils.getPathForFile` 获取本机路径，再由主进程验证文件，不把整个文件读进界面内存。

每片实际上传文件不超过 80 MiB（83,886,080 字节），不是十进制的 80,000,000 字节。切片为有效 ZIP Store 容器，内部 payload.bin 是原文件的一个区间。为 ZIP 头尾保留 512 字节，单片有效载荷为 83,885,568 字节；末片可以更小。切片不能独立安装或打开原文件，需要软件还原。

## 下载与合并

1. 切换到“下载与合并”。
2. 使用“我的蓝奏云”，默认“智能识别”模式。已知切片目录直接复用当前账号的原名缓存，首次遇到的目录在后台逐项读取快速索引或正式清单；普通文件夹照常显示，可进入子目录。行内点击“下载并合并”会完整校验清单再开始，无需填写分享链接或提取码。点击原文件名可先查看详情；外部分享仍可通过完整分享链接和必要提取码读取。
3. 确认保存目录和并发数量（默认 4，范围 1–8）。默认保存到系统“下载”目录下的“蓝奏切片”子目录，可在下载页或设置中更改。
4. 如果先读取详情或分享清单，点击底部“下载并合并”。软件同时下载多个切片，每片按清单验证大小与 SHA-256，再按编号读取 ZIP 内的有效载荷并合并。
5. 最终文件大小与原文件 SHA-256 一致后才报告成功。不覆盖目标目录已有的同名文件。

### 多选右键删除与文件夹选择（0.1.17）

- 普通网盘文件夹现在也支持复选框、行点击、Ctrl 增减选择及 Shift 连选；全选包含已加载的文件和文件夹，最多 200 项。
- 多选后在选中项上点击右键，菜单只显示“删除”。确认框列出本次全部目标，包含文件夹时明确提示会删除整个目录及子项。确认后逐项删除选中内容，未选中的项目保留。
- 部分删除失败时，已成功的项目从列表和选择中移除，确认框只保留失败项；再次确认只重试剩余项。账号变化会停止后续删除，本地下载结果和历史记录保留。
- “下载所选”的数字仅统计可直接下载的普通文件和已识别切片。普通文件夹可选中管理；需要下载其中内容时进入目录选择文件。

### 文件行右键菜单（0.1.16 起）

- 在普通文件、文件夹或智能识别的切片条目上点击右键，即可使用原“更多”中的重命名、删除；行内“更多”入口也可使用。
- 右击已选项目保留多选；右击未选的文件或文件夹会单选该项。单选菜单提供重命名、删除；多选菜单只提供删除选中项，确认框显示全部目标。
- 菜单跟随鼠标位置并在窗口边缘自动避让。按 Esc、点击菜单外或滚动列表可关闭；刷新目录、切换页面/视图/账号后关闭，读取目录或提交操作期间不能打开管理菜单。

### Ctrl / Shift 多选（0.1.15）

- 点击文件行的空白、大小或时间区域单选；按住 **Ctrl** 点击文件行或名称，添加或取消该项，保留其他选择。复选框仍可直接增减选择。
- **Shift＋点击** 从上一次普通点击或 Ctrl 点击的条目连续选择，按当前列表顺序计算，包含文件和文件夹。支持向上、向下连选，重复 Shift 点击可调整范围；**Ctrl＋Shift＋点击** 在已有选择上追加连续范围。
- 修饰键也支持复选框及切片原名；Ctrl/Shift 点击切片原名只选择，不读取详情。普通点击切片原名仍查看详情，“下载”“更多”等操作按钮继续执行各自操作。
- 加载更多及后台识别重绘保留选择锚点。清除选择、全选、目录/模式/账号切换、手动刷新或成功加入批量队列时重置锚点。连选也遵循每批 200 项上限。

### 多选与批量下载（0.1.14）

- 在“我的蓝奏云”的文件列表中勾选多项，点击“下载所选”。普通文件与智能识别出的切片文件可以混选；表头复选框全选已加载项，“清除选择”取消勾选。每批最多 200 项，未加载的后续页面不自动选入；普通文件夹不加入下载队列，需进入后选择文件。
- 加载更多和后台识别更新保留当前选择；切换目录、智能/原始模式或账号，以及手动刷新目录时清空选择。原始模式按实际文件下载，不自动将切片目录合并。
- 多个文件加入后台队列，依次下载；切片文件开始时重新校验正式清单，并按下载页或设置中的并发数下载切片、校验和自动合并。普通文件使用单连接。已有传输未结束时可排队，单个文件失败不会阻断其余文件，也不覆盖已有的同名结果。
- 在“上传下载”页查看“排队中”任务，可暂停单项或“暂停全部”。账号过期时暂停剩余队列；重启后未完成及排队记录恢复为暂停，核实账号后可逐项继续。清空历史保留排队、运行和暂停任务。

### 下载页文件管理（0.1.12）

- “我的蓝奏云”在智能与原始两种视图均可管理文件。普通文件行点击“下载”直接保存到当前下载目录；切片条目继续点击“下载并合并”。原始模式中的 ZIP 或清单按实际文件下载，不会自动当作完整原文件。
- 文件与文件夹行的“更多”提供重命名和删除，工具栏可在当前层“新建文件夹”。操作使用 YunX 的蓝奏云接口，服务端确认后更新列表并清除相关原名与目录快照缓存；失败保留原条目并可重试。
- 删除先显示确认，默认聚焦“取消”。普通文件夹删除包含全部子目录；切片条目明确显示原名和实际云端目录，并删除整个切片目录。删除云端内容不删除本地下载结果或历史记录，但后续依赖该内容的任务可能无法继续。涉及正在运行的传输时需先暂停。
- 切片条目的重命名明确为“重命名云端目录”，不改正式清单和恢复出的原文件名；修改后仍可识别。原始视图可管理实际切片和清单，手动删除或改名后可能无法再进行完整合并。
- 普通下载进入相同的传输管理页和紧凑浮窗，显示字节数、速度、用时、剩余估算，可暂停、继续、打开结果位置及清理记录。普通文件使用单连接；没有可信切片哈希或版本校验器，因此继续时安全地重新下载，不拼接可能已变更的远程内容。切片上传、下载仍按设置并发。
- 普通下载依据实际响应长度检查完整性，不将网盘列表的近似大小或本地摘要冒充远程 SHA-256 校验。服务端未声明长度时显示总量未知；完整响应结束后记录实际大小。通过临时文件和排他提交保存，不覆盖已有同名结果，暂停或失败的缓存保留，完成缓存遵循自动清理设置。

### 速度精度与打开所在文件夹（0.1.13）

- 浮窗和上传下载管理页的速度统一保留两位小数，例如 `4.25 MiB/s`、`1.50 KiB/s`；暂停或无流量时为 `0.00 B/s`。单位按两位小数的精度进位，文件大小、百分比和时间沿用原有取整方式。
- 直接点击浮窗文件名或“打开所在文件夹”；管理页的每个任务也有相同按钮。上传定位原文件，下载完成后定位实际保存的文件（包括恢复后的特殊字符原名），下载未完成时打开该任务的下载目录。若文件被移动或删除而父目录仍在，则打开父目录；目录也不存在时显示提示。
- 使用主进程保存的任务路径打开 Windows 资源管理器，界面只提交任务 ID；不将上传源路径暴露给渲染进程。浮窗仍为 344×128，收起为 344×48，数字区域保持固定尺寸。

### 紧凑传输浮窗（0.1.11）

- 右下角传输浮窗保持 344 像素宽，高度由 218 缩至 128 像素，减少约 41%。已处理/总量移到进度条旁，阶段说明与暂停/继续按钮放在底行；保留原名、进度、速度、已用时间及预计剩余，数值继续四舍五入并保持固定尺寸。
- 收起后仍为 344×48，支持隐藏、重新显示和打开管理页；长名称与阶段说明省略后可悬停查看。仅调整浮窗布局，上传下载管理页沿用原有尺寸。

### 即时识别与普通文件夹（0.1.10）

- 已识别的原文件名、大小和片数按账号与目录 ID 保存。父目录列表读出后立即带上已有预览，不再为每个已知目录重扫子目录；软件刚完成的上传直接用完整上传回执预热原名，下次启动也可复用。预览仍标注“下载前校验”，不把缓存当作下载清单。
- 会话内最近 32 个目录的第一页保留 5 分钟快照。返回已浏览目录时先显示已有列表，同时更新远程内容；更新失败恢复原目录和滚动位置。重启后的父目录列表仍需要网络，首次遇到且没有缓存的旧切片目录仍需至少一次识别，不能保证所有情况无等待。
- 首页文件夹与文件接口并行读取；后台仍最多同时识别两个子目录，每个结果完成就推送显示，无需等待慢目录或整批结束。切换目录、模式或账号后，过时结果不覆盖当前界面。
- 普通文件夹保留原名、文件夹图标和“进入”操作，确认后标注“普通文件夹”；其内部普通文件、多层子目录和空目录正常显示。未识别时先正常展示目录，不再给所有文件夹挂“正在识别切片清单”。含切片痕迹但缺正式清单、缺片或损坏的目录仍报告异常，不误报为可下载文件。
- 切片预览 5 分钟内复用，普通目录分类 1 分钟内复用；过期先展示已有信息并在后台更新，超过 7 天或目录改名后重新识别。点击“刷新目录”会绕过本层识别缓存，远程修改后可主动立即更新。
- 展示缓存位于用户数据目录的 `folder-recognition.json`，最多 1000 条，按账号隔离，不含密码、会话、临时直链或可下载凭据。它与切片恢复缓存、传输历史独立，清空传输历史后仍可识别云端文件。删除此展示缓存只会触发重新识别，不影响原文件或云端内容。
- 本机 HTTP 测试：同一单页切片目录冷识别 3 次子目录请求，命中缓存及从磁盘恢复后均为 0 次；这是识别请求数，父目录读取和下载校验仍需要网络，不能据此承诺真实平台耗时。

### 传输数据、右下角浮窗与集中管理（0.1.9）

- 上传和下载在右下角显示固定尺寸的小浮窗（0.1.11 为 344×128 像素），不再放在文件浏览器下方。显示原文件名、当前阶段、进度百分比、已处理/总量、速度、累计用时和预计剩余时间；可暂停/继续、收起为 344×48、隐藏，或点击“上传下载”打开管理页。管理页的“显示浮窗”可重新打开。
- 传输速度按本次真实传输的字节取最近约 5 秒的平均值。已校验的本地缓存、Range 续传已有字节、哈希和合并不计为网速；重试重新传输的字节计入。连续约 3 秒无新数据后速度归零。网络速度是请求流量估计，不是平台确认写入速度。
- 速度自 0.1.13 起四舍五入到小数点后两位；已传输量和百分比四舍五入到整数；时间按秒四舍五入，显示时:分:秒，超过一天显示天数。浮窗、进度百分比和三个数字区域保持固定尺寸，使用等宽数字，长名称省略并可悬停查看。无有效速度、准备、校验或合并期间不伪造剩余时间，显示“—”。
- 累计用时包含运行时的准备、校验、网络等待和合并，排除暂停及程序关闭的时间；任务进度保存时同时记录用时。旧任务没有统计数据时从零开始，不反推历史用时。预计剩余仅估算当前网络传输阶段，不包含后续校验和合并。
- 新增独立“上传下载”页，按上传/下载及排队中/进行中/暂停/失败/完成筛选，显示任务总数与各状态数量。支持暂停全部、单任务继续、打开结果位置、导出清单、展开实际目录/分享详情、单条移除和批量清理。每次仍只运行一个文件任务，文件内切片按设置并发。
- “清空已完成”保留失败恢复记录。“清空全部历史”清除已完成和失败的记录及可确认归属的切片缓存；清除失败记录后不能从原缓存继续。排队、运行和暂停任务保留，原文件、最终下载结果、账号会话、设置、云端文件和未知文件均不删除。单条“移除记录”仅用于已完成或失败任务，遵循同一保护规则。

### 文件名快速索引（0.1.8）

- 新上传完成后，在切片目录额外上传一个 `sliceindex1…txt` 小文件。文件名把原名（包括中文与特殊符号）、原大小、切片数和正式清单 ID 压缩编码为 ASCII 十六进制，并附摘要检查位。目录名继续使用安全的 `slice任务ID`；完整原名和 SHA-256 仍保存在正式清单中。
- 智能识别仍需列出每个候选目录的完整成员，但有有效索引时不再为列表显示而获取清单分享地址、解析下载页、取下载签名或下载清单。单页模拟目录的对照测试为 3 次目录请求，对比完整识别 8 次请求，减少 5 次（62.5%）；不是实际平台耗时或固定倍速承诺，多页目录仍需分页。
- “快速预览”只是发现提示，并非已验证文件。读取预览时检查正式清单 ID、完整片数、切片顺序名称及重名；点击原名或“下载并合并”仍重新下载正式清单，核对切片 ID，再按 SHA-256 下载与合并。索引文件不能代替正式清单或改变下载文件身份。
- 索引只在正式清单提交之后上传。索引上传失败不影响已完成文件；任务卡片会显示说明，继续使用完整清单。索引提交时暂停，继续任务会复用已确认或响应丢失的同名索引，避免重复上传。
- 旧目录无需迁移。索引缺失、格式损坏、重复、清单 ID 不匹配或成员不完整时自动回退完整清单；旧目录不会自动被写入新文件。编码后索引文件名超过 240 个 ASCII 字符时跳过索引，保留完整原名，继续完整清单识别。
- 读取完整清单后，目录内智能视图将匹配的索引和切片一起折叠；原始网盘模式仍可查看这些实际文件。缓存和历史清理识别本机 `slice-index.txt` 临时文件，保留原有归属及恢复保护。

### 原始网盘与智能识别（0.1.7）

- 下载页顶部可切换“智能识别”和“原始网盘”，选择自动保存。旧配置默认使用智能识别。
- 智能模式把清单完整、切片齐全的目录显示为原文件：独立图标、蓝色原文件名、“切片文件”标记及原大小；已识别条目排在前面。次行保留切片数量和实际云端目录名，悬停可看完整名称。
- 点击原文件名可查看详情及展开 SHA-256；点击行内“下载并合并”直接开始，下载前重新核对远程清单和切片。运行任务时禁用其他一键下载入口。
- 点击“查看切片”会切换到原始模式并打开实际目录。原始模式按实际云端名称显示文件夹、ZIP 切片和清单，不自动发起新的子目录识别扫描。
- 在切片目录内切回智能模式，会自动读取完整清单，将清单和已知切片折叠为一个原文件条目；其他普通文件继续显示，不会隐藏或删除。切换模式不会修改任何云端内容。
- 识别失败时直接显示原因并提供“重试识别”，不把未完成或损坏的目录冒充可下载文件。切换模式、目录或账号后，迟到的识别结果不会覆盖当前列表。
- 修复下载参数解析：支持带引号的 `data` 键、命名参数对象、变量别名、字符串拼接及转义、编码表单、重定向后的页面地址和同源嵌套下载 iframe。仅静态读取参数，不执行远程脚本；不支持的模板和人工验证会明确报告，不能绕过外部分享密码或验证码。

### 并发传输（0.1.6）

- 打开“设置与清理”，在“传输并发”中分别设置上传和下载路数，均支持 1–8 路；默认上传 2 路、下载 4 路。设置自动保存，重启后保留。
- 下载页底部的并发选择与设置中的下载并发同步；上传页和任务卡片显示对应并发数量。
- 新任务使用最新设置。运行中的任务保持启动时的并发；暂停或失败后点击“继续”，使用最新保存的设置。
- 并发针对一个文件的多个切片，同时仍只运行一个传输任务；实际并发不超过剩余切片数。每片上传不超过 80 MiB，不对单片额外开启多个上传连接。
- 上传按工作槽位生成并提交 ZIP，确认成功后释放该片缓存，再处理下一片；并发越高，需要同时保留的上传缓存越多。遇到网络或平台限速，可调低路数。
- 切片可以乱序上传完成，正式清单仍按编号排序，全部成功后只提交一次；暂停或失败会等待并发请求退出，保留已确认回执供恢复使用。

### 自动识别、目录与清理（0.1.5）

- 完成上传后再进入下载页，会自动刷新根目录并识别已上传文件。当前层的文件夹按批识别，最多两个文件夹同时读取；加载更多后继续识别，不递归扫描整盘。进入其他目录或切换账号时，迟到的结果不会覆盖当前界面。
- 真正名称来自云端 `manifest.lanzou.txt` 的 `originalName`，清空本地历史、换电脑后仍可重新识别。只显示名称映射，不修改实际云端兼容目录名；云端目录名仍保留供追踪。缺清单、重复清单、缺片等目录不能被当作可下载文件。
- “无需提取码”指已登录账号可访问的目录。软件自动按现有账号接口获取文件信息和下载链接；不会绕过外部分享密码或平台验证。
- “设置与清理”中可选择默认下载目录、切片缓存目录和自动清理开关。更改缓存位置时，会在所选位置建立 `LanzouSliceCache` 专用子目录；只影响新任务。已有任务继续使用其原始缓存与输出路径，旧版任务也按旧路径恢复。
- 新版切片缓存与任务日志分开：每个任务有独立 UUID 缓存目录及归属标记。暂停或失败的任务不会因为切换目录、普通缓存清理或“清空已完成”丢失恢复数据；0.1.9 的“清空全部历史”会明确包含失败记录。缓存和下载结果在不同磁盘时分别检查可用空间。
- 自动清理默认开启，在传输完成和校验成功后、以及启动时，清理已完成任务的残留切片。关闭后保留完成下载的切片供手动清理；上传时仍逐片释放已确认上传的 ZIP，以控制磁盘占用。
- “刷新占用”显示可清理缓存和受保护的恢复数据。“清理缓存”仅删除本软件可确认归属的已完成任务临时文件，不递归删除用户所选目录，不跟随任务缓存目录联接。
- “清空已完成”一键移除已完成上传/下载记录及可清理残留缓存；正在运行、暂停和失败的任务保留。原文件、最终下载结果、登录会话、目录设置及云端文件保留。

### 界面与操作（0.1.4）

- 文件列表按名称、大小、修改时间和操作分列，表头固定；文件夹、普通文件、压缩包和切片清单有不同图标。
- 长文件名和目录路径省略显示，悬停可查看完整内容；加载更多时保留列表滚动位置，进入目录时回到顶部。
- 已登录后的账号栏收起网页登录选项，点击“网页登录与会话”仍可打开；登录与隐私说明折叠显示。
- 上传区显示已选文件的名称、路径和大小；0.1.9 起任务位于独立“上传下载”页，详情可展开，实时进度移至右下角可收起浮窗。提示消息位于右上角。
- 保留原有蓝白风格和文件列表主导的布局，不改变蓝奏云登录、切片传输或校验协议。

### 文件浏览布局（0.1.3）

- 文件列表随窗口高度伸展，宽屏使用可用宽度；目录内容在列表内部滚动，保存位置、并发设置和下载按钮保留在底部。
- 下载标题缩小，移除下载区的宣传标题和重复说明。“读取清单”放入目录工具栏，下载设置合并为一行；完整保存路径可悬停查看。
- 分享链接入口保留紧凑表单，上传、分页、清单校验和原名恢复逻辑不变。

### 文件目录读取（0.1.2）

- 按固定版本 YunX 的 `LanzouApi.listCloudFiles`，使用 `doupload.php` 的 `task=47` 读取文件夹，`task=5` 和 `pg` 读取文件，沿用同一 Cookie 会话和 `uid/vei`。
- 已登录后首次进入“下载与合并”会读取第一页，点击“加载更多”继续读取，不必等待全部文件扫描完。界面显示已读数量、页码、文件大小与修改时间。
- 按 YunX 的字段优先级处理 `fol_id/id`、`name/name_all`，跳过空条目并去重；遇到重复文件页停止，防止无限翻页。读操作遇到频率限制或 HTTP 服务异常时，最多重试同一请求两次，不跳页。
- 目录成功读出后才更新路径；失败会保留原列表和原路径。退出/切换账号后，旧目录请求的迟到响应不会覆盖新状态。
- 找到 `manifest.lanzou.txt` 后，可直接点击该行的“读取清单”。清单检查和实际下载仍会读取完整目录、核对所有切片；浏览第一页不会被当作完整切片列表。

### 特殊符号与原名恢复（0.1.1）

- 上传时自动使用兼容的云端目录名，切片名仍为 `part-000001.zip` 等；不改动本地原文件，也不因原文件名中的符号弹出“名称含有特殊字符”。
- 云端 `manifest.lanzou.txt` 的 `originalName` 完整保留原名，`naming` 记录原名、云端目录名和命名策略。修复旧失败任务时还记录 `previousCloudFolderName`，任务卡片显示实际云端目录。
- 下载合并时直接恢复清单里的原文件名，包括中文、空格、括号、`&`、`+`、全角符号和 emoji 等 Windows 支持的字符。
- 如果来自其他系统的清单原名含 Windows 无法保存的字符（如 `:`、`?`、`/`、`\\`）、保留设备名、末尾点/空格，软件自动使用安全名称；过长名称保留短哈希避免截断混淆。完整原名仍保存在清单、本机 `task.json` 中，`nameRestoration` 记录原名与实际保存名，任务卡片会显示转换结果。Windows 禁用的字符不能直接作为文件名落盘。
- 旧版本因目录名报错的任务可在新版点击“继续”自动修复；已经存在的旧云端目录和 v1 清单继续兼容，避免重新上传已确认的切片。

本软件的“多线程”是多个切片并发传输，不额外对每个切片开启多连接；未完成切片仅在下载节点正确支持 Range 时按字节续传，否则重新下载该片。

## 暂停、关闭和恢复

- 任务运行时可点击“暂停”；退出软件会先暂停并保存任务。
- 重启后点击“继续”。已确认上传的片不重传；已下载的片重新校验后复用。
- 上传切片的单次请求中断后，按片重传，没有单片上传的字节级断点续传。
- 上传响应丢失时先查询远程同名片，并下载校验其 SHA-256，再确定是否重传，避免仅按名字/大小误判。
- 继续上传时原始文件必须留在原位置且内容未修改。
- 分享下载任务的提取码不写入任务日志；重启后如需要提取码，在分享入口重新填写，再点击任务“继续”。
- 成功后按“自动清理缓存”开关处理临时片；失败和暂停时保留恢复数据。不会自动删除云端内容。

## 数据与清单

点击“打开本地任务目录”可查看本机任务记录。默认位于 Electron 的用户数据目录 lanzou-slice-desktop。记住登录使用 session.bin（Windows 系统加密）；任务日志在 tasks/，设置在 settings.json，默认切片缓存在 cache/。退出账号会清除本地登录会话并暂停任务。新版账号传输任务绑定创建时的账号，切换账号后需登录原账号才能继续；旧日志没有账号标记时保持兼容。

正式清单为 manifest.lanzou.txt（UTF-8 JSON），包含原文件名、名称映射（新版上传）、大小、SHA-256、切片顺序、偏移、有效载荷长度、封装大小、切片 SHA-256 与远程文件 ID，不包含账号密码、Cookie 或临时下载直链。

正式清单在全部切片上传成功后才提交。下载入口拒绝缺清单、缺片、重名或无效清单。

第一版只支持本项目的新清单协议，不承诺兼容其他切片工具、此前已删除网页版本的旧清单、蓝奏云优享版或其他网盘。
